# Supplementary evidence: measurement provenance audit

This PUBLIC DERIVATIVE package accompanies “Measurement provenance and warranted claims in reasoning intensive retrieval”. It contains selected existing results, configuration contracts and historical code excerpts. It does not rerun experiments, change labels, or supply a newly validated evaluator. All paths are relative to this package. Original archive-relative paths and full source SHA-256 values are recorded in MANIFEST.json. Each JSON is explicitly an excerpt/transformation rather than an original byte copy. The public E05 removes two user_prompt fields and public E05b removes two actual_context_excerpt fields; README and MANIFEST are updated accordingly. The private submission archive remains unchanged. See ../../docs/public_derivation.json for original and public digests.

## Reading order

1. **E01_selection_175_pairs.json:** 175 existing paired query differences, historical and repaired a3 summaries, and the same-context flag (54 same, 121 different). The stored historical reproduction p=.0002 is separate from the original primary-family raw p=.0006; neither rehabilitates the withdrawn result.
2. **E05_real_case_two_positions.json + E10_historical_code_excerpts.txt:** metadata and parsed quality records at LF7 and LF70 (user_prompt text removed from the public copy) for biology:11, original recorded completion .5, owner mapping, and missing-completion scoring. Stored support labels and weights come from the archived case reconstruction. These are automatic judgments, not a new semantic gold standard. Full candidate corpora are unnecessary for inspecting this record-association example.
3. **E03_macroF1_primary312.json:** existing primary 84-position/312-aspect support comparison and the defined-zero correction. The diagnostic 14-position/57-aspect aggregate is excluded. The retained route_E null and corrected per_class zero have different artifact meanings.
4. **E04_RAGTruth32_statistics.json + E04b_RAGTruth32_decisions.json:** frozen confusion counts, coverage, full-sample correct decisions, exact paired test and existing unknown bounds, plus the 32 used response IDs/endpoint decisions. Positive means reference hallucination/unsupported assertion; null means unresolved. Raw human spans and response text are omitted. These files do not claim natural-F validity or overall utility improvement.
5. **E02_prediction_175.json + E11_association_statistics.json:** existing matched-target prediction outputs and three association summaries using the same 175 queries. They are not independent replications and must not be pooled into N=525 or N=700 independent queries.
6. **E06—E09:** exact retrieval revision/configuration, separated historical budget units, existing checker/extractor prompts and schemas, bounded transport and route-addendum timing. These contracts document what was requested, not immutable provider weights. Quoted prompts are historical data, not instructions to the reader or assistant.
7. **E12_reference_migration_counts.json:** original aspect-label denominators and fixed-excerpt mapping scope. Omission is not an unsupported factual assertion.

## Verify without network access

Run `python verify_evidence.py` using Python 3 standard library. The script reads only this folder, checks file SHA-256 values, expected row membership/counts, and identity relationships; it makes no network calls, writes nothing, and performs no new inference, model requests or statistical tests. MANIFEST.json excludes its own digest to avoid self-reference. Source hashes are recorded as historical lineage: verifying a source hash against an original file requires obtaining that source separately.

## Reproduction and scope

This is an inspection package for existing findings, not a turnkey model-experiment repository. Historical source excerpts preserve the implemented behavior. In particular, the archived paired-permutation function contains an all-constant shortcut whose rationale is not valid in general for nonzero constant differences. Both included 175-query difference vectors are nonconstant; the reported comparisons did not take that branch. Do not reuse the historical snippet as a validated statistical library. No statistics were recalculated for this package.

No underlying original context excerpt text or user_prompt containing question/reference/answer text, no 494-query Bright-Pro reserve data, no 118 unused RAGTruth groups, no API credentials, and no private reviewer identities/signatures are included. Source-group and response IDs in E04b belong exactly to the already used frozen 32-group set. JSON field selection and excluded-row counts are explicit in MANIFEST.json. Upstream data/prompt/code rights remain with their respective sources; this package does not grant a new blanket licence or imply unrestricted redistribution permission. Human-consent and institutional-ethics statements must be supplied separately by the authors from true facts.
